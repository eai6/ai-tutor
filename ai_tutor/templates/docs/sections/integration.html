No connector to any national education management system ships with the platform. Integration is through a versioned REST API with token authentication, which covers:

  • Authentication, registration and the current user.
  • Courses, lessons, lesson steps and per-lesson competency.
  • Starting and driving tutoring sessions.
  • Offline packs per lesson, and synchronisation of work done offline.
  • Device registration for provisioned machines.

A machine-readable API schema is published by the application itself, so an integration team can generate a client rather than read prose. Student records carry a field for the identifier used by the school information system, which is the intended join key for a roster synchronisation built on top of the API.

A REALISTIC INTEGRATION SCOPE FOR A PILOT

Roster import and results export, both as scheduled jobs against the API, are enough for a first term. Live bidirectional synchronisation with a national system is a project of its own and should not sit on the critical path to a first cohort.
