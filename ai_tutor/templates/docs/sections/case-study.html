The platform was built for one country and then taken to a second, in a different language and a different education structure. This is the real change list, offered because it is a better estimate of effort than any general claim about configurability. No database schema redesign appears in it.

AreaChange
Language registrationAdded the locale to the platform language list; added a tutor identity profile naming the audience as that country's secondary students in that country's own grades; added a language-and-register rule for live tutoring; added the matching rule for content generation.
Language resolutionAdded per-school default language and per-student preferred language, and the request-time resolution chain that puts the course's language first inside a session.
Interface translationTranslation catalogues for the interface in the new language, including the JavaScript strings; page-by-page localisation of the staff management and bulk student upload screens; the resume banner; exit-ticket result messages.
De-assuming the first countryRemoved Seychelles assumptions from the answer grader; scoped the local fact library by locale so one country's facts cannot ground another country's courses; stopped the tutor describing students in the new country as Seychellois.
Education structureMade grade level country-flexible and configuration-driven rather than a fixed choice set — which also fixed a registration failure for students whose grade did not exist in the original list — and made course routing match on the country's own grades.
Defaults and terminologyNew-language platform defaults and locale-aware platform terminology; a staging environment running with the new language as its default.
ContentThe syllabus ingestion, generation and expert review loop — the largest workstream, and the one that is genuinely proportional to the number of subjects in scope.

Two things are worth drawing out of that list. First, the engineering is mostly removing an assumption, not adding a feature — and each assumption removed makes the third country cheaper than the second. Second, almost everything in the first six rows is now a registration point rather than a code change: adding a country to the tutor engine today is a locale profile entry and a language rule, with no database change.
