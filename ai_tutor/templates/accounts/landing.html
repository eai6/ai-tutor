{% trans "How one lesson goes" %}

  1. 1 {% trans "Engage" %} {% trans "Opens with a question about something the student already knows." %}
  2. 2 {% trans "Explore" %} {% trans "The student works the idea out loud; the tutor asks rather than tells." %}
  3. 3 {% trans "Explain" %} {% trans "The idea gets named and tied to the curriculum's own wording." %}
  4. 4 {% trans "Elaborate" %} {% trans "A harder case, to see whether it holds outside the first example." %}
  5. 5 {% trans "Exit ticket" %} {% trans "A short check. The score is what the teacher sees the next morning." %}
{# ────────────────────────────────── what it does ────────────────────── #}

{% trans "It teaches the syllabus the school already uses" %}

{% blocktrans %}A teacher uploads the curriculum — schemes of work, past papers, worksheets. The platform turns it into lessons and keeps every answer grounded in that material, so a student is not being taught a different course from the one they sit an exam in.{% endblocktrans %}

{% icon "chat" %}

{% trans "Talks, doesn't lecture" %}

{% trans "Every step is a question. A student who answers correctly moves on; a student who doesn't gets a smaller step, not the answer." %}

{% icon "target" %}

{% trans "Measures what stuck" %}

{% trans "Each lesson ends with an exit ticket. Scores are per objective, so a teacher sees which idea a class missed, not just who scored low." %}

{% icon "shield" %}

{% trans "Watched, not unattended" %}

{% trans "Conversations are checked for harmful, inappropriate and manipulative content. Anything flagged goes to a named teacher to review." %}

{% icon "students" %}

{% trans "One device, two students" %}

{% trans "Where devices are shared, a teacher can pair students into groups and the tutor runs the lesson for the pair." %}

{% trans "Reports for the teacher" %}
